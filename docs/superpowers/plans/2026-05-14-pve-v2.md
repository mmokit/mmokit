# PVE v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship PVE v2 per [docs/superpowers/specs/2026-05-13-pve-v2-design.md](../specs/2026-05-13-pve-v2-design.md): telegraphed AoE primitive, projectile primitive, four new player weapons, Artillery + Kamikaze NPC archetypes (Sniper/Swarmer deleted), station POI moved to a fixed anchor 1100u north of station, fair-by-design invariant test.

**Architecture:** Two new ECS primitives (`AoEMarker`, `Projectile` entities + their components + their game-side systems) feed everything else. NPC AI casts AoE markers; player abilities fire projectiles that on impact apply direct damage and optionally spawn instant-lifetime AoE markers for splash. AoESystem resolves expired markers via `gw.ApplyDamage`. System order: `Ability → Projectile → StatusEffect → NPCAI → AoE → ...` so all same-tick AoE resolves before tick end.

**Tech Stack:** Go (server, ark ECS via `pkg/mmokit` facade), TypeScript + PixiJS (web client, auto-generated SDK), PostgreSQL persistence (untouched here).

**Architecture note (deviation from spec §3):** The spec mentions `AoESystem` in `pkg/system/`. In practice, both the AoE and Projectile systems live in `internal/game/` because they call `gw.ApplyDamage()` directly. Moving them to `pkg/system/` would require a damage-callback abstraction layer that isn't worth the cost for v2. Note the deferred refactor in §11 of this plan.

```go
	OwnerNetID  uint32  `net:"auto"`
	FactionMask uint8   `net:"auto"`

}
```

```go
// internal/component/projectile.go
package component

// ProjectileSpec describes a travel-time projectile fired by a player
// ability (or future NPC). ProjectileSystem moves it each tick via the
// entity's Velocity, performs swept collision against the spatial grid,
// and on first non-owner hit:
//   - applies Damage to the hit target via gw.ApplyDamage
//   - if SplashRadius > 0, spawns an AoEMarker with Lifetime=0 at the
//     impact point (resolves same tick via AoESystem)
//   - despawns the projectile
// On lifetime expiry without a hit, despawns silently.
//
// Homing: if TargetNetID != 0, ProjectileSystem rotates Velocity toward
// the target each tick capped by MaxTurnRate (rad/s). If the target is
// dead or out of range, TargetNetID is zeroed and the projectile
// continues on its current heading (dumb-fire).
//
// Type is purely a visual variant for the client renderer.
type ProjectileSpec struct {
	OwnerNetID   uint32  `net:"auto"`
	TargetNetID  uint32  `net:"auto"`
	Damage       float32 `net:"f32"`
	SplashRadius float32 `net:"f32"`
	SplashDamage float32 `net:"f32"`
	MaxTurnRate  float32 `net:"f32"` // rad/s; 0 = no homing
	Type         uint8   `net:"auto"` // 0=Plasma, 1=Missile, 2=Mortar
}

// Projectile-type visual variants. Must match the corresponding
// constants in web-pixi/src/entities/projectile.ts.
const (
	ProjectileTypePlasma  uint8 = 0
	ProjectileTypeMissile uint8 = 1
	ProjectileTypeMortar  uint8 = 2
)
```

```go
// internal/game/system_aoe.go
package game

import (
	"math"

	gamecomp "github.com/mmokit/mmokit/internal/component"
	"github.com/mmokit/mmokit/pkg/mmokit"
)

// FactionMask bits (game-defined; passed to AoESpec.FactionMask).
const (
	FactionMaskNPC    uint8 = 0x01
	FactionMaskPlayer uint8 = 0x02
	FactionMaskAll    uint8 = 0x03
)

// AoESystem resolves expired AoEMarker entities. Each tick:
//   1. For markers with Lifetime.Remaining <= 0:
//        a. Query spatial grid in Spec.Radius.
//        b. For each non-owner hit matching Spec.FactionMask, call
//           gw.ApplyDamage.
//        c. Despawn the marker via Commands().
//
// Registered AFTER ProjectileSystem and NPCAISystem so instant-lifetime
// markers (Kamikaze detonate, projectile splash) resolve same-tick.
type AoESystem struct {
	mmokit.SystemBase
	gw       *GameWorld
	entities mmokit.Query[struct {
		Pos      *mmokit.Position
		Lifetime *mmokit.Lifetime
		Spec     *gamecomp.AoESpec
	}]
}

func (s *AoESystem) Init() {
	s.gw = mmokit.State[GameWorld](s.Stage())
}

func (s *AoESystem) Update(dt float32) {
	gw := s.gw
	for entity, b := range s.entities.Iter {
		if b.Lifetime.Remaining > 0 {
			continue
		}
		marker := mmokit.EntityFromECS(gw.stage, entity)
		s.resolveMarker(marker, b.Pos, b.Spec)
		s.Commands().Despawn(marker.Handle())
	}
}

// resolveMarker queries the spatial grid and applies damage to all
// eligible victims in radius. Owner is always skipped.
func (s *AoESystem) resolveMarker(marker mmokit.Entity,
	pos *mmokit.Position, spec *gamecomp.AoESpec,
) {
	gw := s.gw
	r2 := spec.Radius * spec.Radius
	victims := gw.spatial.QueryRadius(pos.X, pos.Y, spec.Radius)
	for _, v := range victims {
		victim := mmokit.EntityFromECS(gw.stage, v)
		if !victim.Alive() {
			continue
		}
		netID := victim.NetID()
		if netID == spec.OwnerNetID {
			continue
		}
		// Distance check (spatial grid returns by cell, not by exact radius).
		vpos := mmokit.Get[mmokit.Position](victim)
		if vpos == nil {
			continue
		}
		dx, dy := vpos.X-pos.X, vpos.Y-pos.Y
		if dx*dx+dy*dy > r2 {
			continue
		}
		if !s.factionMatch(victim, spec.FactionMask) {
			continue
		}
		gw.ApplyDamage(victim, spec.Damage, spec.OwnerNetID)
	}
	gw.eng.Log.Log(CatCombat, "aoe: resolved at (%.0f,%.0f) r=%.0f dmg=%.0f hits=%d",
		pos.X, pos.Y, spec.Radius, spec.Damage, len(victims))
	_ = math.Sqrt // keep math import if other helpers added later
}

// factionMatch returns true if the victim's faction matches the spec's
// FactionMask. NPCs match bit 0; players match bit 1.
func (s *AoESystem) factionMatch(victim mmokit.Entity, mask uint8) bool {
	if mmokit.Has[gamecomp.NPCAI](victim) {
		return mask&FactionMaskNPC != 0
	}
	if mmokit.Has[gamecomp.PlayerConn](victim) {
		return mask&FactionMaskPlayer != 0
	}
	return false // anything else (asteroid, station, loot) is invulnerable
}
```

```go
// internal/game/system_projectile.go
package game

import (
	"math"

	gamecomp "github.com/mmokit/mmokit/internal/component"
	"github.com/mmokit/mmokit/pkg/mmokit"
)

// ProjectileSystem moves Projectile entities, performs swept collision
// against the spatial grid, applies impact damage, and on impact
// optionally spawns an AoEMarker for splash. Runs BEFORE AoESystem so
// splash markers spawned this tick resolve same-tick.
//
// Homing: if Spec.TargetNetID != 0 AND the target is alive, the
// velocity vector is rotated toward the target each tick capped by
// Spec.MaxTurnRate (rad/s). If the target is gone, TargetNetID is
// zeroed and the projectile continues straight.
type ProjectileSystem struct {
	mmokit.SystemBase
	gw       *GameWorld
	entities mmokit.Query[struct {
		Pos  *mmokit.Position
		Vel  *mmokit.Velocity
		Life *mmokit.Lifetime
		Spec *gamecomp.ProjectileSpec
	}]
}

func (s *ProjectileSystem) Init() {
	s.gw = mmokit.State[GameWorld](s.Stage())
}

func (s *ProjectileSystem) Update(dt float32) {
	gw := s.gw

	for entity, b := range s.entities.Iter {
		proj := mmokit.EntityFromECS(gw.stage, entity)
		pos, vel, spec := b.Pos, b.Vel, b.Spec

		// Homing
		if spec.TargetNetID != 0 && spec.MaxTurnRate > 0 {
			target := mmokit.EntityByNetID(gw.stage, spec.TargetNetID)
			if !target.Alive() {
				spec.TargetNetID = 0
			} else if tpos := mmokit.Get[mmokit.Position](target); tpos != nil {
				s.steerToward(vel, pos, tpos, spec.MaxTurnRate, dt)
			}
		}

		// Missile acceleration (Type=ProjectileTypeMissile): ramp up to cruise speed
		if spec.Type == gamecomp.ProjectileTypeMissile {
			speed := float32(math.Sqrt(float64(vel.X*vel.X + vel.Y*vel.Y)))
			const cruiseSpeed = float32(350)
			const accel = float32(150) // u/s²
			if speed < cruiseSpeed && speed > 1e-3 {
				newSpeed := speed + accel*dt
				if newSpeed > cruiseSpeed {
					newSpeed = cruiseSpeed
				}
				ratio := newSpeed / speed
				vel.X *= ratio
				vel.Y *= ratio
			}
		}

		// Move
		pos.X += vel.X * dt
		pos.Y += vel.Y * dt

		// Collision: query a tight radius around the projectile.
		const projHitRadius = float32(4)
		hits := gw.spatial.QueryRadius(pos.X, pos.Y, projHitRadius)
		var victim mmokit.Entity
		for _, h := range hits {
			e := mmokit.EntityFromECS(gw.stage, h)
			if !e.Alive() {
				continue
			}
			if e.NetID() == spec.OwnerNetID {
				continue
			}
			// Only collide with NPCs and players, not asteroids/loot/stations.
			if !mmokit.Has[gamecomp.NPCAI](e) && !mmokit.Has[gamecomp.PlayerConn](e) {
				continue
			}
			victim = e
			break
		}

		if victim.Alive() {
			gw.ApplyDamage(victim, spec.Damage, spec.OwnerNetID)
			if spec.SplashRadius > 0 {
				mask := factionMaskFromOwner(gw, spec.OwnerNetID)
				gw.SpawnAoEMarker(pos.X, pos.Y, 0, spec.SplashRadius, spec.SplashDamage, spec.OwnerNetID, mask)
			}
			s.Commands().Despawn(proj.Handle())
			continue
		}

		// Lifetime expiry (no hit)
		if b.Life.Remaining <= 0 {
			s.Commands().Despawn(proj.Handle())
		}
	}
}

// steerToward rotates `vel` toward the heading from `pos` to `tpos`,
// capped by maxTurnRate (rad/s). Preserves speed.
func (s *ProjectileSystem) steerToward(
	vel *mmokit.Velocity, pos *mmokit.Position, tpos *mmokit.Position,
	maxTurnRate, dt float32,
) {
	speed := float32(math.Sqrt(float64(vel.X*vel.X + vel.Y*vel.Y)))
	if speed < 1e-3 {
		return
	}
	curHeading := float32(math.Atan2(float64(vel.Y), float64(vel.X)))
	desired := float32(math.Atan2(float64(tpos.Y-pos.Y), float64(tpos.X-pos.X)))
	delta := desired - curHeading
	for delta > math.Pi {
		delta -= 2 * math.Pi
	}
	for delta < -math.Pi {
		delta += 2 * math.Pi
	}
	maxDelta := maxTurnRate * dt
	if delta > maxDelta {
		delta = maxDelta
	} else if delta < -maxDelta {
		delta = -maxDelta
	}
	newHeading := curHeading + delta
	vel.X = speed * float32(math.Cos(float64(newHeading)))
	vel.Y = speed * float32(math.Sin(float64(newHeading)))
}

// factionMaskFromOwner returns the AoE FactionMask appropriate for a
// projectile owned by the given netID. Player-owned projectile splash
// damages NPCs; NPC-owned splash damages players.
func factionMaskFromOwner(gw *GameWorld, ownerNetID uint32) uint8 {
	if ownerNetID == 0 {
		return FactionMaskAll
	}
	owner := mmokit.EntityByNetID(gw.stage, ownerNetID)
	if owner.Alive() && mmokit.Has[gamecomp.PlayerConn](owner) {
		return FactionMaskNPC
	}
	return FactionMaskPlayer
}
```

```go
func (s *AbilitySystem) fireProjectile(
    caster mmokit.Entity, params *item.AbilityParams, projType uint8,
) {
    gw := s.gw

    casterRot := mmokit.Get[mmokit.Rotation](caster)
    if casterPos == nil || casterRot == nil {

    }

    // Direction: toward the active target if any, else muzzle-forward.
    dirX, dirY := math32Cos(casterRot.Angle), math32Sin(casterRot.Angle)
    var targetNetID uint32
    if lock := mmokit.Get[gamecomp.TargetLock](caster); lock != nil {
        if target, ok := activeLockTarget(gw, lock); ok {

                    targetNetID = target.NetID()
                }
            }
        }

        TargetNetID:  targetNetID,
        Damage:       params.Damage,
        SplashRadius: params.SplashRadius,
```

```go
    FairnessFocusFire FairnessFactor = 0.0
```

```typescript
// web-pixi/src/entities/aoe-marker.ts
import { Container, Graphics } from "pixi.js";
import type { AoEMarkerEntity } from "../../sdk"; // exact import path per generated SDK

// AoEMarkerRenderer draws a telegraphed AoE: an outer dashed ring at
// full Radius (intent) plus an inner filled circle expanding 0 → Radius
// over the marker's Lifetime (commitment). Color depends on FactionMask:
//   bit 0 (NPC-damaging) → red/orange
//   bit 1 (Player-damaging) → red/orange
//   The owner is always presumed hostile from the player's POV — this
//   client only ever sees server-spawned markers.
export class AoEMarkerRenderer {
    container: Container;
    private outer: Graphics;
    private inner: Graphics;
    private radius = 0;
    private initialLifetime = 0;
    private remaining = 0;

    constructor(entity: AoEMarkerEntity) {
        this.container = new Container();
        this.outer = new Graphics();
        this.inner = new Graphics();
        this.container.addChild(this.outer, this.inner);
        this.updateFromServer(entity);
        // Capture initial lifetime once for progress math.
        this.initialLifetime = entity.lifetime?.remaining ?? 0.1;
    }

    updateFromServer(entity: AoEMarkerEntity) {
        this.container.x = entity.position.x;
        this.container.y = entity.position.y;
        this.radius = entity.spec.radius;
        this.remaining = entity.lifetime?.remaining ?? 0;
        this.redraw();
    }

    private redraw() {
        const progress = this.initialLifetime > 0
            ? Math.max(0, Math.min(1, 1 - this.remaining / this.initialLifetime))
            : 1;

        // Outer dashed ring — full radius, low alpha
        this.outer.clear();
        this.outer.setStrokeStyle({ width: 2, color: 0xff5544, alpha: 0.6 });
        this.outer.circle(0, 0, this.radius);
        this.outer.stroke();

        // Inner filled disc — grows with progress
        this.inner.clear();
        this.inner.beginFill(0xff3322, 0.25);
        this.inner.circle(0, 0, this.radius * progress);
        this.inner.fill();
    }

    destroy() {
        this.container.destroy({ children: true });
    }
}
```

- [ ] **Step 2: Implement the three visual variants**

The simplest approach: a small colored circle with a trailing line. Variants differ only in color + radius:

- **Plasma (Type=0):** cyan dot, 3px radius, short trail
- **Missile (Type=1):** orange dot, 4px radius, long trail
- **Mortar (Type=2):** yellow dot, 5px radius, arcing trail (cosmetic — server-side it's straight)

Use a `Graphics` per renderer; redraw with the variant's color on construct. The position lerps automatically via the interpolation pipeline used by other entities.

```typescript
// web-pixi/src/entities/projectile.ts (additions)
import { Container, Graphics } from "pixi.js";
import type { ProjectileEntity } from "../../sdk";

const COLOR_BY_TYPE: Record<number, number> = {
    0: 0x33ddff, // Plasma — cyan
    1: 0xffaa33, // Missile — orange
    2: 0xffee33, // Mortar — yellow
};
const RADIUS_BY_TYPE: Record<number, number> = { 0: 3, 1: 4, 2: 5 };

export class ProjectileRenderer {
    container: Container;
    private body: Graphics;
    constructor(entity: ProjectileEntity) {
        this.container = new Container();
        this.body = new Graphics();
        const t = entity.spec.type ?? 0;
        const color = COLOR_BY_TYPE[t] ?? 0xffffff;
        const r = RADIUS_BY_TYPE[t] ?? 3;
        this.body.beginFill(color);
        this.body.circle(0, 0, r);
        this.body.fill();
        this.container.addChild(this.body);
        this.updateFromServer(entity);
    }
    updateFromServer(entity: ProjectileEntity) {
        this.container.x = entity.position.x;
        this.container.y = entity.position.y;
    }
    destroy() {
        this.container.destroy({ children: true });
    }
}
```

## Implementation Notes / Gotchas

1. **`gw.spatial.QueryRadius` exact signature** — the spec assumes this method exists. If it's actually `spatial.Within(x, y, r)` or similar, adapt. Don't invent a new API. Look at existing systems (e.g. CollisionSystem) for the canonical call.

2. **`mmokit.ForEach1` vs query** — for the SustainedBeam channel tick we use `ForEach1[Channeling]` to iterate every entity with a Channeling component. Confirm this helper exists; if it's called something else (e.g. `mmokit.Each`), use that. The pattern (one-shot iteration outside the system's bound query) is what matters.

3. **`item.AbilityParamsFor`** — needs a way to look up params by AbilityType outside of a per-slot iteration. If it doesn't exist, add a public helper to `internal/item/item.go` that returns the params struct for a given AbilityType.

4. **`activeLockTarget`** is defined at the top of `system_ability.go`. Reuse it.

5. **`spawnPOIRoster`** signature — varies. Match what the existing POISystem uses to spawn roster members.

6. **Configurable interface for runtime tuning** — new GameConfig fields automatically work with `config get/set/list` via the reflection-based Configurable adapter in `pkg/engine/configurable.go`. No additional wiring needed.

7. **Deferred ECS mutations** — every spawn/despawn inside a system tick MUST go through `s.Commands()`. Direct `stage.Spawn` is allowed because spawn is not iteration-time-mutating (creates a new entity in a separate ark step), but check by reading the Stage.Spawn implementation if uncertain.

8. **Web-pixi Pixi version** — read `web-pixi/package.json` to confirm Pixi v7 vs v8 API before writing renderer code. The example code in Tasks 27-28 uses v8 syntax; downgrade to v7 if needed.
