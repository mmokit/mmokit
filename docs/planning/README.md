# Planning history

**Status:** Historical index, not a maintained backlog or architecture
specification.

Documents in this area record design exploration. They can explain intent, but
current source, tests, and package documentation are authoritative for shipped
behavior.

The former `mmokit-roadmap.md` and `mmokit-target-architecture.md` were retired
in July 2026 because they mixed dated target designs with current-state claims
and duplicated the detailed plans and specifications retained under
[`docs/superpowers`](../superpowers/). Their paths now contain short retirement
notices so links from historical plans remain valid; Git history retains the
original content.

Use these sources instead:

- [Core engine improvement roadmap](../roadmaps/core-engine-improvements.md) —
  maintained priorities identified by the July 2026 engine review.
- [`docs/superpowers/specs`](../superpowers/specs/) and
  [`docs/superpowers/plans`](../superpowers/plans/) — dated design records;
  useful context, never proof of current behavior.
- Repository source, tests, `AGENTS.md`, and the nearest package README —
  current implementation and contributor guidance.

New active tracking documents belong in `docs/roadmaps`. Keep dated design
artifacts explicitly labeled with their status and review date.
