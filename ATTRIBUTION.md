# Attribution

Everything in this repository is original work covered by [`LICENSE`](LICENSE)
(MIT). There are no bundled third-party assets.

That is a deliberate property rather than a happy accident, and it is worth
stating because game repositories usually cannot say it.

## Audio — generated, not sampled

The sixteen Ogg files under `examples/space/web/public/audio/` are synthesised
from oscillators and seeded noise by
[`examples/space/web/tools/gen-audio.py`](examples/space/web/tools/gen-audio.py),
using only the Python standard library plus ffmpeg for Vorbis encoding. No
sample, recording, or download is involved. Regenerate with:

```bash
python3 examples/space/web/tools/gen-audio.py
```

Filenames are the contract — `SoundId` in
`examples/space/web/src/audio/sounds.ts` keys sounds by filename — so the
generator writes exactly the sixteen names that file expects, and nothing else.

**History note.** An earlier set of sixteen files occupied these paths, added in
a single commit with no recorded source. Their only provenance evidence was
embedded Vorbis metadata: four carried `ARTIST=KenneyG`, eleven carried
`COMMENTS=Sound generated by GameSynth from Tsugi`, one carried only LMMS's
default export string, and four carried nothing. A metadata tag is an
authorship claim, not a licence grant, so those files were replaced rather than
relabelled — attribution cannot manufacture a redistribution right that was
never established. They were also removed from the repository's history, since
deleting a file from the working tree leaves its bytes reachable in every
clone.

## Art — drawn, not loaded

There are no image, sprite, or font files either. All game art is drawn
procedurally with PixiJS `Graphics` (75 call sites across 26 files; zero
`Assets.load`, zero `Texture.from`). Verified with git's own binary detection
over every tracked file: the sixteen `.ogg` files above are the only non-source
assets in the repository.

## Dependencies

Go, JavaScript and C# dependencies are declared in `go.mod`, the `package.json`
files, and the `.csproj` files, and are fetched rather than vendored — no
third-party source is copied into this tree.

Every Go dependency is MIT, BSD-3-Clause, Apache-2.0 or ISC. The only copyleft
anywhere in the transitive JavaScript graph is MPL-2.0 `lightningcss`, a
build-time CSS transformer in the admin dashboard's Tailwind pipeline, which is
not redistributed.
